# ClearPathFBA — Pilot Clinician Onboarding

**What it does.** ClearPathFBA turns the ABC and baseline observations you already collect into a defensible Functional Behavior Assessment: it analyzes the data for a likely behavioral function, then generates a ready-to-sign FBA report, Behavior Intervention Plan, crisis plan, data sheets and progress reports.

**Signing in.** Go to app.clearpathfba.com and sign in on the **Sign in** screen with the username and password you were sent (plus a 6-digit code if you enabled multi-factor).

**Your first session (20 minutes)**

1. **Create a client** — click **＋ New client** in the header, enter first and last name, then **Save profile**.
2. **Open an assessment** — with the client selected, click **＋ New assessment**, add a title and yourself as Assessor, then **Save assessment**.
3. **Add a target behavior** — in **Target behaviors** click **＋ Add target behavior**: name, operational definition, a **Safety classification** if it applies, **Baseline measurement type**, then **Add behavior**.
4. **Log baseline and ABC data** — in **Data collection** click **＋ Record data point** per observation: recorded at, behavior, measurement type, value, setting, antecedent, consequence.
5. **Run the function analysis** — in **Function hypothesis** click **Generate analysis** for a function, confidence percentage, top antecedents and consequences, and a written rationale. If your judgment differs, choose a function and click **Save override → reviewed**.
6. **Generate and sign the FBA report** — in the **Print:** row click **FBA Report**; under **Sign-offs — FBA Report** click **＋ Add signatory**, then **Sign** and **Sign & date**. Each signature is cryptographic over that document: click **Verify signature** any time, and later edits mark it invalid.
7. **Generate the BIP** — open the **BIP** tab; it builds on the same analysis and signs the same way. **Crisis Plan** and **Data Sheet** sit in the same tab row.
8. **Progress reports** — choose **Monthly** or **Quarterly**, type the period (2026-09 or 2026-Q3) in the **Print:** row, click **Progress report**: it compares this period with the previous one and gives each behavior's trend (improved, stable or worsened) plus plan-adjustment recommendations.

Each document also offers **Print / Save as PDF**, **Download Word**, **Download PDF** and a **De-identified** toggle.

**Offline.** If your connection drops the header shows **Offline**; new data points queue on the device and sync when you reconnect (or click **Sync now**). Open each assessment once while online so its behaviors are cached.

**Demo account.** Sign in as **demo@clearpathfba.com** / **DemoPilot2026!** for a sample workspace (Sample Client A, B, C) with analysis, a signed report and a progress report already complete.
